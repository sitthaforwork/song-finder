# 🎵 Song Finder (DEMO)

เว็บแนะนำเพลงฮิต / แนวเพลง พร้อม AI ช่วยหาเพลง (เปรียบเทียบหลายโมเดล) รองรับไทย + อังกฤษ

## วิธีรัน

```bash
npm install
npm start
```

แล้วเปิด http://localhost:3000

> ไม่ต้องมี API key ก็รันได้ — ส่วน AI จะเป็น "โหมดจำลอง" (ข้อมูลตัวอย่าง)
> ส่วนเพลงฮิต / แนวเพลง / ค้นหา ใช้ iTunes API ฟรี ไม่ต้องใช้ key

## ใส่ API key เพื่อใช้ AI จริง (ฟรีทั้งหมด)

1. คัดลอก `.env.example` เป็น `.env`
2. สมัครอย่างน้อย 1 เจ้า แล้วใส่ key (ยิ่งใส่หลายเจ้า ยิ่งเปรียบเทียบโมเดลได้มาก)
   - **Groq** — https://console.groq.com (ไม่ต้องใช้บัตร, เร็วมาก)
   - **Google Gemini** — https://aistudio.google.com (ฟรีเฉพาะรุ่น Flash)
   - **OpenRouter** — https://openrouter.ai (มีโมเดล `:free` หลายตัว)
3. รีสตาร์ตเซิร์ฟเวอร์ (`Ctrl+C` แล้ว `npm start` ใหม่)

> รายชื่อโมเดลฟรีเปลี่ยนบ่อย ถ้าโมเดลไหนขึ้น error ให้แก้ชื่อใน `src/ai.js` (ฟังก์ชัน `baseModels`)
> หรือเพิ่มโมเดล OpenRouter ผ่าน `OPENROUTER_MODELS` ใน `.env`

## โครงสร้างไฟล์

```
song-finder/
├─ server.js        # เซิร์ฟเวอร์ Express + API routes
├─ src/
│  ├─ music.js      # iTunes API + ตรวจว่าเพลงมีจริง
│  └─ ai.js         # เรียก AI หลายโมเดล + โหมดจำลอง
├─ public/
│  ├─ index.html    # หน้าเว็บ
│  ├─ style.css
│  └─ app.js        # ฝั่งหน้าเว็บ (สองภาษา)
├─ .env.example
└─ package.json
```

## หลักการทำงานของ AI ช่วยหาเพลง

ผู้ใช้พิมพ์ → เซิร์ฟเวอร์ถามหลายโมเดลพร้อมกัน → ได้รายชื่อเพลง →
**ตรวจทุกเพลงกับ iTunes** (ตัดเพลงที่ AI แต่งขึ้นทิ้ง) → แสดงผลเทียบกันเป็นคอลัมน์

## โหมด Auto และสรุปผลที่ตรงกัน

- **Auto (ค่าเริ่มต้น)**: ระบบเลือกโมเดลตามภาษาของคำค้น ถามทีละตัวและหยุดทันทีที่ได้เพลง เพื่อประหยัดโควตา
  - เนื้อเพลงไทย → ค้นเว็บ (Tavily + Groq) ก่อน
  - ภาษาอื่น → Gemini ก่อน แล้วค่อยค้นเว็บ
  - ถ้าตัวแรก error หรือไม่เจอ จะลองตัวถัดไป (สูงสุด 3 ตัว) และแสดงลำดับที่ลองให้ดู
- **ติ๊ก Auto ออก** เพื่อเลือกหลายโมเดลมาเปรียบเทียบคู่กัน ซึ่งจะมีกล่อง "เพลงที่โมเดลตอบตรงกัน" สรุปไว้ด้านบน

## ข้อจำกัด

- ไม่รองรับฮัมเสียงเพื่อหาเพลง (ต้องใช้ audio fingerprinting) — รองรับแค่อธิบายทำนองเป็นคำพูด
- ไม่แสดงเนื้อเพลงเต็ม (ลิขสิทธิ์) เล่นได้เฉพาะตัวอย่าง 30 วินาที
- API key เก็บไว้ที่เซิร์ฟเวอร์ (`.env`) ห้ามใส่ในโค้ดหน้าเว็บ และห้ามอัปโหลด `.env` ขึ้น GitHub
